Leonida Nights is an offline cover art maker that turns your own photos into a multi-panel, GTA-poster-style game cover in about three steps. Add one or more photos, pick from four collage layouts (Hero + Two, Three Columns, Grid + Wide Base, Tall Lead + Stack), drag and scroll on the cover itself to frame each panel, then dial in the Vice City neon-sunset grade — saturation and contrast lift, a warm sunset wash, an optional neon duotone — and set your own big gradient caption and sub-caption. Export renders the exact same drawing you previewed to a PNG at 1080×1080, 1080×1350 or 1920×1080. Two bundled demo photos are included so it works the second it opens. Everything runs locally in the browser with no network calls and no build step: your photos never leave your device.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. To hand the entry in, stage the app, screenshots and dossier with:

```sh
node main.ts
```
