Leonida Cover Maker turns your own photos into bold, multi-panel GTA-style cover art with a Vice City neon-sunset grade. Load one or more photos (or use the two bundled demo photos), pick from three poster layouts — Hero + 2, Three panels, or Grid + wide base — then drag each panel to reframe it and scroll or use the slider to zoom. A canvas grade lifts saturation and contrast and lays a magenta, orange and teal sunset wash over every panel, with an optional neon duotone toggle for a punchier look. Add a big bold caption and an optional sub-caption, choose an export size (1080×1080, 1080×1350 or 1920×1080), and export a finished PNG in a few clicks. Everything runs locally in the browser with no build step and no network calls, so your photos never leave your device.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser, add a photo, pick a layout, and press **Export PNG**.

To hand the entry in, build the submission dossier:

```sh
node main.ts
```
